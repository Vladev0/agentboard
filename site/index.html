A task board that remembers what your agents forget.

AgentBoard gives coding agents a durable queue, explicit human handoffs, and project memory. You keep a clean kanban view; the source of truth stays in readable Markdown.

Agents resume cleanly

get_next_task returns the next actionable card after a context reset or a different agent takes over.

02

Blocked work stays visible

A needs-input flag pauses one task without stopping the whole autonomous cycle.

03

Knowledge outlives tasks

Versioned memory notes preserve decisions, formulas, and pitfalls without turning the board into a work log.

A boring file format is a feature

Markdown underneath. A focused interface on top.

Projects, tasks, comments, checkpoints, and memory notes are ordinary files. Search them, diff them, back them up, or sync the folder with tools you already trust.

  • No database and no vendor lock-in
  • Separate agent-complete from human-verified work
  • REST API and 17 MCP tools use the same source of truth

Start locally

Clone, set up, run.

$ git clone https://github.com/Vladev0/agentboard.git
$ cd agentboard
$ npm run setup
$ npm run dev

Or install the MCP bundle from the latest GitHub release. The bundle asks where to keep your vault and configures the MCP server for you.

AgentBoard is free, open source, and released under MIT.
